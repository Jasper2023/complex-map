# Complex Map

Interactive complex-function visualizer. Drop photos and grids onto the z-plane, type any complex function in LaTeX-style math input, and watch the image transform through w = f(z) in realtime (WebGL).

**Live:** https://jasper2023.github.io/complex-map/

Fully static — no build step, no server. Open `index.html` or serve the folder with any static file server.
